# 私有媒体读取

**逻辑版本：** 0.1.0
**追踪项：** DR-001
**Resolved Path:** `docs/active/0.1.0/remediation/dr-001-private-media/`

## Overview

访客、所有者和管理员在通过身份验证后可以查看私密空间中的照片与相册媒体；匿名者和取得旧链接的人不能绕过内容权限读取这些媒体。媒体的持久化标识不依赖任何对象存储供应商。

## Behavior: 受保护内容读取

### Scenario: 已授权访客读取省份照片

Given 访客已取得有效会话，湖南有一张私有照片
When 访客读取湖南照片列表
Then 响应包含该照片的可显示地址
And 该地址的有效期不超过 300 秒

### Scenario: 已授权用户读取不含媒体的内容

Given 所有者已取得有效会话，某省份没有照片
When 所有者读取该省份的照片列表
Then 响应状态为 200
And 响应为空数组且不包含媒体地址

### Scenario: 匿名者读取受保护内容

Given 请求没有有效会话
When 请求省份照片列表、相册列表或相册页面
Then 响应状态为 401
And 响应不包含媒体地址或存储引用

## Behavior: 相册媒体读取

### Scenario: 已授权用户打开含封面和页面图片的相册

Given 所有者已取得有效会话，相册有一张封面和一页两张图片
When 所有者读取相册列表和该相册页面
Then 封面和两张页面图片都能被浏览器显示
And 返回的每个媒体地址有效期不超过 300 秒

### Scenario: 相册没有封面或页面图片

Given 访客已取得有效会话，相册没有封面且页面图片数组为空
When 访客读取该相册
Then 响应保留空封面和空图片数组
And 不为缺失媒体创建签名地址

### Scenario: 已过期会话读取相册媒体

Given 请求携带已过期或已失效的会话
When 请求相册列表或相册页面
Then 响应状态为 401
And 系统不签发新的媒体地址

## Behavior: 管理员私有上传与保存

### Scenario: 管理员取得受限上传凭据

Given 管理员已取得有效会话并选择一张 JPEG、PNG 或 WebP 图片
When 管理员请求上传凭据
Then 系统返回一个上传地址和一个对象标识
And 上传地址有效期不超过 600 秒，且响应不返回读取地址

### Scenario: 管理员保存刚上传的媒体

Given 管理员完成图片上传，且系统已确认对象为不超过 10 MiB 的 JPEG、PNG 或 WebP 图片
When 管理员提交系统确认后签发的一次性上传回执并保存照片、封面或页面图片
Then 后续受保护读取仍能显示该图片
And 回执只能绑定的资源范围消费一次，持久化内容不保存可直接公开读取的地址

### Scenario: 非管理员或非法上传类型

Given 访客已取得有效会话，或请求的文件类型不是 JPEG、PNG 或 WebP
When 请求照片或相册上传凭据
Then 访客请求返回 403，非法类型请求返回 400
And 系统不返回上传地址或对象标识

### Scenario: 上传对象超过大小限制或内容伪装

Given 管理员已经上传一个超过 10 MiB 的对象，或对象声明为图片但文件头不属于 JPEG、PNG 或 WebP
When 管理员请求确认该上传对象
Then 响应状态为 422
And 系统不返回媒体引用或读取地址

## Behavior: 受控存储引用

### Scenario: 迁移前已有的媒体记录继续可读

Given 一条已有记录的旧媒体域名地址已由部署迁移为规范媒体引用
When 已授权用户读取该记录
Then 系统返回新的短期可显示地址
And 响应不返回旧媒体域名地址

### Scenario: 新写入的媒体回执

Given 管理员保存一张新上传的图片
When 系统消费该上传回执
Then 系统仅接受由本次服务器确认、且属于当前资源范围的对象
And 系统保存非公开的规范媒体引用

### Scenario: 不受信任的媒体地址

Given 管理员提交的媒体地址属于未知域名、未知 bucket 或不允许的路径
When 系统保存照片、相册封面或页面内容
Then 响应状态为 400
And 系统不为该地址签发读取权限

### Scenario: 私有化前检查历史记录

Given 部署人员执行历史媒体引用检查
When 检查发现任一记录无法转换为项目允许范围内的媒体引用
Then 检查以失败结果结束并列出记录标识
And 部署人员不得启用私有桶策略

## Constraints

- 私密媒体存储不得配置匿名公开读取。
- 读取地址的签名有效期固定为 300 秒，上传地址的签名有效期固定为 600 秒。
- 读取接口只向 `visitor`、`owner`、`admin` 三种已认证角色返回媒体地址；匿名请求始终返回 401。
- 对同一条响应中的同一个媒体对象最多签发一个读取地址；相册单页最多处理 10 张图片，沿用现有输入上限。
- `POST /media/confirm` 只返回不透明、10 分钟有效的一次性 `uploadReceipt` 与预览用读取地址；浏览器不得获得或提交 `media://` 引用。回执按照片省份或相册范围绑定，并在业务写入事务内消费。
- 系统不得在日志、API 响应或持久化记录中新增永久公开媒体地址。
- 持久化媒体引用必须使用供应商无关的 `media://<logical-key>` 格式；不得包含 bucket、域名、R2、S3、OSS 或其他供应商标识。
- 管理员浏览器仅可从明确配置的后台来源直传；对象存储和 API 不得对任意 Origin 返回 CORS 允许响应。
- 对象存储的匿名直连请求不得返回 2xx；已签发读取地址是临时 bearer 凭据，令牌撤销后的最大既有访问窗口为 300 秒。
